► Bedeutung ◄
CMOS SETUP UTILITY / Bedeutung
BIOS steht für Basic Input/Output System. Es ist die Firmware, die beim Einschalten grundlegende Hardware vorbereitet und den Start des Betriebssystems einleitet.
ZURÜCK
► Firmware ◄
CMOS SETUP UTILITY / Firmware
Firmware ist Software, die fest zu einem Gerät gehört und grundlegende Hardware-Funktionen steuert. Das BIOS ist kein normales Anwendungsprogramm.

CMOS SETUP UTILITY / Speicherort
Die BIOS-Firmware liegt auf einem nichtflüchtigen Speicherchip auf dem Mainboard. Nichtflüchtig bedeutet: Der Inhalt bleibt auch ohne Strom erhalten.

► Was ist MBR? ◄
CMOS SETUP UTILITY / Was ist MBR?
MBR heißt Master Boot Record. Es ist ein älteres Schema für Partitionen und Startinformationen auf einem Datenträger. Es ist nicht dasselbe wie BIOS.
ZURÜCK
► BIOS und MBR ◄
CMOS SETUP UTILITY / BIOS und MBR
Klassisches BIOS und MBR wurden häufig gemeinsam verwendet. BIOS ist die Mainboard-Firmware, MBR ist ein Datenträger-Schema.
ZURÜCK

CMOS SETUP UTILITY / Grenzen von MBR

Eintrag auswählen und ENTER drücken.

► 2-TB-Grenze ◄
CMOS SETUP UTILITY / 2-TB-Grenze
Bei MBR liegt die übliche Größenbegrenzung bei ungefähr 2 TiB, oft vereinfacht 2 TB genannt. Das ist eine Grenze von MBR, nicht des BIOS-Chips.
ZURÜCK
► Partitionen ◄
CMOS SETUP UTILITY / Partitionen
